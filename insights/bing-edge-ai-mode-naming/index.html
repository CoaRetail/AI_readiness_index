BingとEdgeはAI Modeと呼ぶ——行き先はCopilot Searchのまま

BingとEdgeは、AI Modeという表示を試しています。タブもボタンも、開く先はCopilot Searchです。公式の案内は製品名をCopilot Searchのままにしており、GoogleのAI Modeと同じ製品ではありません。

自社サイトを無料で確認する Company Reportで詳しく調べる

THE TAB｜BingのタブはAI Mode

Search Engine Watchは2026年9月27日、MicrosoftがBingとEdgeでAI Modeという表示を試している、と書いています。Bingでは、AI MODEのタブが以前より頻繁に出ます。並ぶのはAll、Images、Videos、Mapsです。タブを開くと、行き先はbing.com/copilotsearchです。Copilot Searchが使っているのと同じ宛先です。Search Engine Watch

EDGE｜アドレスバーのボタン

Edgeでは、既定の検索がBingのとき、アドレスバーにAI Modeのボタンが出るテストです。ボタンは、提案されたプロンプトを開きます。プラスのボタンで、画像やファイルを添付できます。EdgeのAI Modeは、BingのAI Modeの体験へ入り、そこからCopilot Searchへ進み得ます。Search Engine Watchは、MicrosoftがCopilot SearchをAI Modeへ改名すると発表したわけではない、と書いています。

THE SER REPORT｜Copilotのタブ名を置き換える

Search Engine Roundtableは2026年9月25日、Bingが検索タブのCopilotという名前を、AI Modeに置き換える、または改名するテストをしている、と伝えています。AI Modeは、Googleが使っている名前です。同記事は、以前Bingが検索結果上部のAI回答で、CopilotではなくAI Overviewsという名前を使ったことがある、とも書いています。最初に取り上げたのはSachin Patel氏で、XとSearch Engine Watchに投稿しています。SERoundtable

OFFICIAL NAME｜案内ページはCopilot Search

Microsoftの案内ページは、製品名をCopilot Searchとしています。Bingの検索結果に基づき、ウェブ上の情報を読み、サイトを横断して突き合わせ、引用元とリンクを示す、という説明です。このページは、製品名をAI Modeとは呼んでいません。Copilot Search

NOT THE SAME PRODUCT｜重なるのは語彙です

ここで起きているのは、表示上の語がGoogleのAI Modeと重なることです。製品が同じだとは書きません。タブやボタンのラベル、遷移先のURL、公式の案内の製品名は、別々に記録します。ラベルがAI Modeでも、案内がCopilot Searchのままなら、観測表には両方を残します。

WHAT TO LOG｜自社で残す項目

残すなら、Bingのタブ文言、Edgeのボタンの有無と既定の検索、遷移先がcopilotsearchかどうか、観測日時、です。GoogleのAI Modeの定点と、同じ列には入れないでください。

出典： Search Engine Watch 2026-09-27／Search Engine Roundtable 2026-09-25／Microsoft Copilot Search（案内ページの製品名。AI Modeへの改名発表ではない）
