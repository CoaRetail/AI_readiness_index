Agent Readiness/ Insights/ 計測の回数

2026.10.28 Column

AIでの見え方は、何問・何回測れば信じられるか

フェアテックの自社計測では、同じ質問の翌日の言及は86〜91%揃い、月単位の目安はAI2つ以上、50問以上、週1回です。グラッドキューブの自社計測では、毎回名前が出た質問は3.0%で、1回は平均26.2ポイントずれました。ツール会社のデータです。

同じ質問を翌日に聞くと、結果はどれくらい揃うか？

AIでの見え方について、名前が出るかどうかは86〜91%揃いました。フェアテックの辰巳裕介氏は2026年10月22日、同社のSourcePick AIOで測った自社データを、プレスリリースで公開しています。2026年9月1日から10月2日、30ブランド、642問、5つのAI、102,510件の回答です。AIはChatGPT、Gemini、Claude、Perplexity、GoogleのAIによる概要です。記録したのは、回答にそのブランドの名前が出たかです。推薦の順位ではありません。

同じAIに同じ質問を翌日聞くと、出るかどうかは86〜91%一致した、と書いています。ばらつきの約半分から3分の2は、どの質問をどのAIに聞いたかで決まる、とも書いています。同じ日に3回聞いても、情報は1.3〜1.4倍にしか増えない、とも書いています。あるAIでは、ある日を境に多くのブランドの言及率がそろって3〜5ポイント上がりました。先月より上がったことが、施策の効果とは限らない、という注意です。26ページのPDFは、会社名と氏名とメールのフォームの奥にあり、この記事では取得していません。数字はプレスリリースに出ている範囲です。同社は計測ツールを売っています。

何問を、いくつのAIで、どの間隔で測る目安か？

目的で分かれます。90%の信頼区間で、上下5ポイント以内に収める目安として、プレスリリースは次のように書いています。月単位で、名前が出る割合が先月より上がったかを見るなら、AIは2つ以上、50問以上、週1回です。毎日なら20問以上、とも書いています。週単位なら、AIは2つ以上、30問以上を毎日、または週2回なら100問以上です。買い手の質問全体で、どのくらい候補に挙がるかを知るなら、50問以上、できれば100問程度で、AIの数と頻度はあまり関係しない、と書いています。

30問を50問にしても、誤差は約2割しか減らない、とも書いています。誤差を半分にするには質問数を4倍にする、質問を増やす価値は種類を広げて見落としを減らすことにある、とも書いています。これは同社の条件での目安で、どのサイトでも同じ回数で足りる保証ではありません。最初の4回で一度も名前が出なかった質問は、次の4回も94%が言及率10%以下のままだった、と書いています。これはAIが5つの場合です。

自社名が毎回出る質問は、どのくらいか？

3.0%です。株式会社グラッドキューブの佐谷建斗氏は2026年10月19日、同社のLLMOAで測った21サービス、2026年3月から9月、25,281件の回答をINSIGHT CUBEに書いています。10回以上測った892通りのうち、毎回名前が出たのは27通りで3.0%、一度も出ないのは45.3%、出たり出なかったりは51.7%です。推薦型の質問で毎回出たのは1.4%、自社名を含む質問では37.0%、解説型では0%です。0%は、解説型では毎回出た質問が無かった、という意味です。

1回の計測が平均26.2ポイントずれる、というのは、全質問の平均ではありません。25回以上測り、しかも言及が揺れた282通りから無作為に1回を抜くと、期間全体の言及率から平均26.2ポイントずれた、という数字です。10回でも平均7.4ポイントです。質問を全部合計した言及率を、期間の前半と後半で比べると、差の中央値は0.0ポイントでした。1問の上下と、合計の安定は、別です。ChatGPT、Gemini、PerplexityはAPI経由で、一般のアプリと同じとは限らない、と書いています。相関であり、因果ではない、とも書いています。匿名の21サービスで、業界の代表ではありません。ツール会社の自社調査です。

3つのAIの平均で決めた1位は、1つ外しても残るか？

残らない業界があります。AIpediaは2026年10月27日、運営元Marketing Cloud LabのツールAIOPulseの公開ランキングを、同社が集計した、と書いています。全体の数字は、ChatGPT、Gemini、Claudeの単純平均です。48業界でChatGPTを外すと、首位が入れ替わる、または同率になる業界は19です。Geminiを外すと8、Claudeを外すと6です。1つの業界が複数に数えられる、と書いています。全体で10ポイント以上離れていても、ChatGPTを外すと崩れる業界は7です。首位が3通りとも残る、と同社が呼ぶ業界は21です。この呼び方は、同記事が置いた基準です。

各ページの集計は8〜9日で、値のある日はChatGPTが4〜5日、Geminiが2〜3日、Claudeが8〜9日です。市場の真の首位ではない、とAIpediaが書いています。同社は、このデータが自社ツールのものだと記事の中で明記しています。料金の比較は、ここでは使いません。同じ市場を測る事業者には利害があります。Envoyraは2026年秋の報告で、AI可視性ツールの区分を測り、自社もその区分の事業者だと書いています。こちらのブランド別の件数は、この記事では使いません。

順位の数字は、この計測と同じように読めるか？

読めません。言及率の揺れと、検索順位ツールが受け取る結果の揺れは、別の不確かさです。順位計測のNozzleは、Derek Perkins氏の2026年10月21日更新で、8月20日から9月9日を基準に、9月13日以降、1ページ目と2ページ目の両方を判定した検索結果の22.6%を汚染としました。基準期間は0.28%です。日次の最高は9月30日の43.5%です。汚染とした結果のうち、通常のサイトが3日以内に戻ったのは67.9%です。定義は、そのページに普段出るサイトの半分未満しか、結果のどこにも無いことです。普段は、基準期間の検索結果の少なくとも60%にいたサイトです。GoogleがAIの収集へ応じた、というのはNozzleの読みです。

Search Engine LandのDanny Goodwin氏は2026年10月27日、Semrushが、自動の順位ツールへ不正確な結果が返っていると認めた、と書いています。Semrush自身の声明のURLは、この記事では取れていません。同じ記事は、Googleはコメントしていない、とも書いています。9月中旬から10月の順位の上下だけを、AIでの見え方の施策の証拠にはしません。言及を数える計測とも、母数が違います。1回の前後で効果を判断しない、という話は別の記事です。名前は出ても選ばれない——言及と推薦は別の数字か

出典： フェアテックのプレスリリース 2026-10-22（辰巳裕介氏。SourcePick AIOの自社データ。30ブランド、642問、5つのAI、102,510件、2026-09-01から10-02。名前の有無。翌日の一致は86〜91%。月単位の目安はAI2つ以上、50問以上、週1回。毎日なら20問以上。PDF本文は未取得）／グラッドキューブ INSIGHT CUBE 2026-10-19（佐谷建斗氏。LLMOAの自社調査。21サービス、25,281件、2026年3〜9月。10回以上の892通りで毎回3.0%、一度も45.3%。推薦型の毎回は1.4%。26.2ポイントは、揺れた282通りの1回のずれ。合計の前後差の中央値は0.0ポイント。API経由。相関）／AIpedia 2026-10-27（AIOPulseの公開ランキングを運営元が集計。単純平均。ChatGPTを外すと48業界中19。10ポイント以上でも7。自社ツールだと明記）／Nozzle 2026-10-21更新（22.6%は9月13日以降、両ページを判定した検索結果。基準0.28%。最高43.5%は9月30日。67.9%は3日以内に通常のサイトが戻る。Googleが原因だというのはNozzleの読み）／Search Engine Land 2026-10-27（Semrushが不正確な結果を認めた、という報道。Semrush自身の声明URLは未取得。Googleはコメントしていない、と書いている）
