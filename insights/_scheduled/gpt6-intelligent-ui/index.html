答えが使える画面になる——GPT-6のIntelligent UI

答えが使える画面になる、とOpenAIはGPT-6のIntelligent UIを説明しています。図やボタンは会話の中で動きます。出典のページがなくなる、とは書いていません。検索で回答が早く始まる点は、同社の内部評価です。

自社サイトを無料で確認する Company Reportで詳しく調べる

UI｜回答が、操作できる部品を混ぜる

OpenAIは2026年10月7日、ChatGPTのGPT-6に Intelligent UI を入れる、と書いています。質問に応じて、文字、図、タップできるボタン、フォーム、チャート、会話の中で使える部品を組み合わせます。比較は横並びがよいことがあり、説明は図を操作した方がよいことがあり、短い文字が最も役立つときは文字のままです。特別な頼み方は要らない、とヘルプセンターは書いています。週にChatGPTを使う人は12億人を超える、とOpenAIは書いています。これは同社の人数です。OpenAI

例として告知が挙げるのは、日曜のローストの時間をレシピの横に置くこと、ドライブの立ち寄りを地図に出すこと、貯金の計算機、割り勘、会話の中のゲームです。部品は、あらかじめ用意したライブラリと、生成しながら組むコンパイラです。回答の全部を待たずに、画面が出てきます。デザインの判断を良くする仕事は、まだ残っている、とも書いています。

SEARCH｜探す品質は、内部評価の主張

ウェブ検索が要る質問では、GPT-6 Instant は GPT-5.6 Instant より、回答を始めるまで平均で44%早い、とOpenAIは書いています。難しい問題の内部評価では、質問の要点に正しく当たった回が GPT-5.6 より多かった、とも書いています。その割合は、告知にありません。いつ調べるかをよりよく決め、答えを支える情報をより安定して見つける、とも書いています。これはOpenAIの表現です。外部が追試した引用の割合ではありません。

別の内部評価では、価値の高い日常の作業について、GPT-6 Extra High は GPT-5.6 Medium と同じ時間で回答を始め、総合点は GPT-5.6 Extra High よりよかった、と書いています。標本の大きさは、告知にありません。どちらもOpenAIの評価です。どのドメインが引用されたかの分布は、この告知にはありません。

PAGE｜出典のページに残る仕事

画面は会話の中で動きます。回答を使う方法は、クリックだけではなくなります。OpenAIが書いているのは、調べるタイミングと、答えを支える情報の見つけ方です。支える情報の置き場として、ページがなくなる、とは書いていません。どの種類のページが引かれやすいかは、この告知の数字ではありません。要約より一次情報——ChatGPTの引用が寄っている先に、別の観測を分けています。クリックが分析のどの区分に入るかは、ここでは書きません。ChatGPTの訪問が「直接」に入る——計測が消えたのか、訪問が減ったのか

ヘルプセンターは、ウェブの設定で Layout and visuals を切ると、視覚的な要素を減らせる、と書いています。一部は残ることがあり、昔の文字だけの画面には戻らない、とも書いています。Intelligent UI に別の利用枠はありません。既存のモデルと、ツールと、プランの枠が適用されます。Proの思考レベルでは使えず、そこは GPT-6 Astra のままです。古い macOS と Windows のデスクトップアプリは非対応で、ウェブを使う、とも書いています。これらはヘルプの記述です。10月7日の告知には、Proでは出ない、とは書いていません。OpenAI Help Center

WHO｜無料とGoは、文書が二つある

10月7日の告知では、Intelligent UI 付きのGPT-6は、その日に Plus、Pro、Business、Enterprise のチャットへ広がり始め、翌日から Free と Go へ広がる、と書いています。有料の段は GPT-6 Sol、Free と Go は GPT-6 Luna です。Enterprise は管理者の設定によります。このリリースでは、Work と Codex を動かすモデルは変えない、とも書いています。

ヘルプセンターのページは、2026年10月15日の取得時に「5日前に更新」と表示されていました。暦日はありません。そこでは、Free と Go の標準と Think は GPT-5.6 Luna で、GPT-6 Sol の思考レベルはない、と書いています。Intelligent UI は、GPT-6 の Instant から Extra High を使うときに、ウェブと、対応する更新済みアプリへ広がる、とも書いています。有料向けの告知と、ヘルプの無料の記述は食い違っています。いま誰の画面に出ているかを、この記事は決めません。

出典： OpenAI 2026-10-07（Intelligent UI。週12億人超は同社の人数。検索が要る質問で回答開始が平均44%早い、は内部評価）／OpenAI Help Center（取得時は「5日前」。暦日なし。視覚要素は減らせるが文字だけには戻らない。FreeとGoの記述は告知と食い違う）
