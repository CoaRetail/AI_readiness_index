Agent Readiness/ Insights/ preferred source

2026.10.07 Column

preferred sourceの件数はメールにある——「preferred」には「含める」が要る

Search Consoleは、preferred sourceに選ばれた件数をメールで知らせています。データは2026年10月5日時点です。AI OverviewsとAI Modeの「preferred」には、設定が「含める」である必要があります。子の上書きは、トップレベルのドメイン所有者に通知されます。

自社サイトを無料で確認する Company Reportで詳しく調べる

EMAIL｜件数は、10月5日時点のメールにある

Search Engine Roundtableは2026年10月6日、Search Consoleが preferred source の件数をメールしている、と報じています。Barry Schwartz氏が受け取ったメールは、"People are choosing domain as a preferred source" と、"Preferred source selections"、データ時点の "as of 2026-10-05" を示しています。読者がサイトを選ぶと、Top Stories、AI Overviews、AI Modeでコンテンツが出やすくなる、とも書いています。推奨として書かれているのは、ページへJavaScriptのボタンを置くことです。あわせて、Search Consoleでのレポートをどう受け取りたいかを聞く調査が付いています。Search Engine Roundtable

同じ日、Glenn Gabe氏、Nati Elimelech氏、Kyle Sutton氏が、自分もメールを受け取ったと書いています。Nati Elimelech氏は、Search Consoleの画面にレポートは見つからない、と書いています。これは受け取った人の報告です。Googleが「画面には出さない」と書いた文は、本稿では確認していません。確認できるのは、メールが件数を運び、調査が将来のレポートの受け取り方を聞いている、ということです。スクリーンショットに写った一つの件数は、一つのプロパティの値です。他のサイトの目安には使いません。

BADGE｜「preferred」には、設定が「含める」である

Googleの案内は、preferred sources を選んだユーザーに対し、Top Storiesでは "preferred" のバッジが付き、AI ModeとAI Overviewsでも同じバッジが付き得る、と書いています。AI ModeとAI Overviewsでその表示の対象になるには、Search Consoleの Search generative AI features にサイトが含まれている必要があります。案内の最終更新は2026年9月18日UTCです。メールで新しく置かれた条件ではありません。Search Central

制御のページでは、三つの選び方があります。既定の "Include" は、サイトのリンクとコンテンツが AI Overviews、AI Mode、Discoverの生成AI機能に出られ、回答の根拠にも使われ得ます。"Exclude" は、それらの機能での表示と、根拠としての使用を止めます。親があるプロパティの既定は "Inherit" です。除外は、制御が有効になってから1〜2日が目安で、キャッシュによりそれより長いことがあります。ヘルプは、この制御を検索の他の部分の順位や収録の信号には使わない、と書いています。学習を限る手段は、別の Google-Extended です。Search Console Help

preferred source として選べるのは、ドメインとサブドメインです。案内の例では、https://www.example.com/ と https://code.example.com/ は対象で、https://www.example.com/blog のようなサブディレクトリは対象外です。

OVERRIDE｜上書きは、トップレベルの所有者に通知される

同じヘルプは、子プロパティの所有者が、親の設定に従うか、その子と配下だけを変えるかを選べる、と書いています。継承は、継承をやめた最も近い親からです。どの親も手動で止めていなければ、トップレベルのドメインの制御を継承します。トップレベルのドメイン所有者は、子プロパティが親の設定を上書きすると、制御のページで通知を見ます。ヘルプの文は、"Owners of the top-level domain property will see a notification on the Search generative AI control page when one of their child properties overrides the parent setting." です。Search Engine Roundtableは2026年10月6日、この一文が追加された、と報じています。通知の画面そのものは、同記事も撮っていません。Search Engine Roundtable

フォルダの除外が、ドメイン全体の preferred バッジを消す、とはヘルプは書いていません。書けるのは、次の三つです。AI OverviewsとAI Modeの preferred 表示には、サイトが Include である必要がある。子プロパティは、自分の範囲を Exclude にできる。その上書きは、トップレベルのドメイン所有者の制御ページに通知される。サブディレクトリは preferred source の選択対象ではなく、AI機能の制御はURLプレフィックスの子プロパティにも置ける、という範囲の違いも残ります。

SIDEBAR｜出典欄のボタンは、限定のテスト

Search Engine RoundtableのBarry Schwartz氏は2026年10月19日、AI Modeの出典欄に Source preferences というボタンを置くテストを報じています。押すと優先ソースの一覧が開き、その場で追加と削除ができる、とあります。見つけたのはDamien Andell氏で、Xに動画を出しています。Schwartz氏自身の画面には出ていません。限定のテストです。Googleの告知は、この記事にありません。Search Engine Roundtable

ボタンの有無は、件数のメールでも、生成AI機能への Include でもありません。AI Modeで preferred と付く条件は、上の案内のままです。出た割合は、記事にありません。

WHAT TO CHECK｜件数と、子の設定を分ける

残すなら、メールの日付、プロパティ名、件数、そのプロパティが Include か Exclude か Inherit か、子の上書き通知があるか、です。一つのサイトの件数を、業界の平均にはしないでください。
