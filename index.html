    About

    Research Hubとは

    Agent Readiness Research Hubは、AIが企業をどのように理解し、比較し、推薦し、予約・問い合わせ・購入などの行動につなげるかを研究・公開するオープンリサーチプラットフォームです。

    技術的なサイト整備（構造化データ・llms.txt等）は、その行動準備度を支えるシグナルの一部として扱います。ARI全体はTechnical Readiness Scannerではありません。

    Framework、Research、Whitepaper、Evidence、Methodologyを継続的に公開しています。

    Agent Readiness Index™

    Frameworkを診断へ

    Agent Readiness Frameworkを企業ごとに評価し、100点満点で可視化した診断指標が Agent Readiness Index™ です。Company Reportでは、自社がAIにどう認識され、どこで比較・推薦・行動につながっていないかを把握し、次に直すべき優先順位を明確にします。

    Framework → Index → Company Report という流れで、評価基準に基づく経営判断材料を提供します。
